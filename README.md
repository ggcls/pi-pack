<h1 align="center">
  pi-pack
</h1>

Monorepo for the pi extensions I develop.

Requires Pi `1.4.0` or a compatible later release. See each extension's README for compatibility details.

## Extensions

### [pi-whimsical](packages/pi-whimsical/README.md)

Replace Pi's working message with a random whimsical message.

### [pi-run-metrics](packages/pi-run-metrics/README.md)

Display metrics about the current run.
